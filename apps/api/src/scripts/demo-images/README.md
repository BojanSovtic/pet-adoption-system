# Demo photos (optional)

`pnpm demo:seed` uploads a photo for a demo pet if a file named after the pet is here, for example `max.jpg`, `luna.png` or `kiki.webp` (lowercase pet name; JPEG, PNG or WebP; at most 5 MB). Pets without a file get no photo.

Before adding a photo:

- Use your own photos or ones explicitly free to reuse (CC0 / public domain).
- Remove the metadata. The app stores photos as uploaded, and phone photos often contain the GPS location where they were taken.
- Keep them small (about 1200 px wide, under 300 KB) so the repository stays light.
